2026-09-16 — Release-readiness pass

A broad correctness and hygiene pass ahead of the first public push.

Fixed

  • Validation now correctly reports type, range, required-key, and unexpected-key problems it was silently missing before (out-of-range ability scores, non-Boolean flags, missing required ATTACKS fields, and more) — the fix landed in the shared validate.dsl library this project depends on, not in this repo directly.
  • A YAML document that never sets ATTACKS at all no longer crashes every layout.
  • Several character sheets that rendered fine on one layout but crashed on another (a free-text ATTACK value, PASSIVE PERCEPTION over a layout’s built-in numeric limit, an empty PROFICIENCIES list, a MAGIC list with no level markers, a FEATURES description containing \par, EQUIPMENT positioned relative to a FEATURES section that didn’t exist) now render correctly on all three layouts.
  • An extremely long, unbroken value in a coin field (CP/SP/etc.) that got rejected by validation could leave the rendered PDF’s error page malformed. Fixed by only ever LaTeX-wrapping long values at render time, after validation has already seen the real value.
  • The web backend (render.cgi) now actually enforces its render timeout — previously it only bounded charsheet itself, not the pdflatex/xelatex process it starts, which could keep running (and consuming CPU) indefinitely past the configured limit.
  • The web backend no longer echoes raw Lua tracebacks or LaTeX’s internal compile log to whoever submitted a sheet; only charsheet’s own intentional, user-facing messages are shown. The full detail is still saved locally for debugging.
  • The web backend’s CORS policy is now consistent between the preflight request and the actual response — previously only the preflight checked the origin allowlist.
  • A symlink planted at the backend’s fixed debug-capture path could previously redirect that write to an attacker-chosen file.

Added

  • mk test runs the full regression suite (testing/formcrash’s fuzz sweep, the hand-built testing/crashers corpus, and the QUICKSTART.html round-trip check) and is now a prerequisite of every target that actually ships something (bundle, publish, push).
  • testing/formcrash runs under GNU parallel (one job per core by default; set $NPROC to override) — the full sweep dropped from about 6 minutes to well under 2.
  • Documented several accepted-but-previously-undocumented YAML.html keys (SPELLS PREPARED, CANTRIPS KNOWN, SUGGESTED NAMES, SUGGESTED MOTIVATIONS, the shared spell-count formula syntax).
  • A private/public repository split: this repository (and its full history) stays private; lib/sync-public maintains a filtered public mirror with private-only paths removed from every commit, not just the current tree.

Changed

  • Repo cleanup: removed stray editor backup files, dead .gitignore entries, and a personal filesystem path from AGENTS.md.
